== What you need

|===
| Role | Requirement

Provided by the facilitator:

* A shared OpenShift cluster with the SPIRE stack deployed via OpenShift GitOps.
* One OpenShift user account per participant (`user1` through `user10`).
* The SPIRE trust domain and cluster domain (printed on this Showroom page).

[NOTE]
====
This lab uses the OpenShift Web Terminal for all CLI commands.
There is no built-in Showroom terminal — you will open one inside the OpenShift Console.
====

== Open your terminal

. Log in to the OpenShift Console using the URL and credentials in your RHDP order.
. In the top navigation bar, click the *>_* (Web Terminal) icon.
. If prompted to select a project, enter `default`.
+
Expected result: A terminal panel opens at the bottom of the console window. // UNVERIFIED

== Run the pre-flight check

Paste these lines into your Web Terminal to set your personal namespace and verify access:

[source,bash]
----
NS=$(oc whoami)-spire-lab
echo "Your namespace: $NS"
oc get namespace "$NS"
oc auth can-i get pods -n "$NS"
oc auth can-i get pods -n {spire_operator_ns}
----

Expected result: `echo` prints `Your namespace: userN-spire-lab`; the namespace is `Active`; both `auth can-i` lines print `yes`. // UNVERIFIED

[IMPORTANT]
====
Every command in this lab uses the `$NS` variable for your personal namespace.
Re-run `NS=$(oc whoami)-spire-lab` if you open a new terminal tab.
====
