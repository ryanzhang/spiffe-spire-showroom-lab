== 你需要准备什么

[cols="1,2",options="header"]
|===
| 角色 | 需要的东西

| 每位参与者
| OpenShift 用户账号和密码（在你的 RHDP 订单邮件中）

| 每位参与者
| 浏览器，能访问 OpenShift Console（链接在 RHDP 订单中）
|===

由 Facilitator 提供：

* 已通过 OpenShift GitOps 部署 SPIRE 全套组件的共享集群
* 每位参与者一个 OpenShift 账号（user1 到 user10）
* SPIRE trust domain：`{trust_domain}`
* 集群 Console：link:https://console-openshift-console.{cluster_domain}[console-openshift-console.{cluster_domain}^]

[NOTE]
====
本实验使用 OpenShift Web Terminal 执行所有命令。Showroom 没有内置 terminal — 你将在 OpenShift Console 内打开 Web Terminal。
====

== 打开你的 Terminal

. 用 RHDP 订单中的 URL 和账号密码登录 OpenShift Console。
. 在顶部导航栏点击 *>_*（Web Terminal）图标。
. 如果提示选择项目，输入 `default`。
+
Expected result: Console 底部出现 terminal 面板。// UNVERIFIED

== 运行飞行前检查

将以下命令粘贴到 Web Terminal，设置你的命名空间并验证权限：

[source,bash,role="execute",subs="attributes+"]
----
NS=$(oc whoami)-{lab_ns_suffix}
echo "你的命名空间：$NS"
oc get namespace "$NS"
oc auth can-i get pods -n "$NS"
oc auth can-i get ZeroTrustWorkloadIdentityManager --subresource="" -n ""
----

Expected result：`echo` 打印 `你的命名空间：userN-{lab_ns_suffix}`；namespace 状态为 `Active`；两个 `auth can-i` 均打印 `yes`。// UNVERIFIED

[IMPORTANT]
====
本实验所有命令都使用 `$NS` 变量引用你的私有命名空间。开新 terminal 标签后需重新运行 `NS=$(oc whoami)-{lab_ns_suffix}`。
====
