== 参与者清理

删除你在命名空间中创建的所有资源：

[source,bash,role="execute",subs="attributes+"]
----
NS=$(oc whoami)-{lab_ns_suffix}
oc delete pod spiffe-demo -n "$NS" --ignore-not-found
oc delete serviceaccount spiffe-demo-sa -n "$NS" --ignore-not-found
oc delete ClusterSPIFFEID $(oc whoami)-demo --ignore-not-found
----

Expected result：每行输出 `deleted` 或 `not found`。// UNVERIFIED

验证你的命名空间已清空：

[source,bash,role="execute",subs="attributes+"]
----
oc get all -n "$NS"
----

Expected result：`No resources found in <ns> namespace.` // UNVERIFIED

== Facilitator 清理

[WARNING]
====
以下步骤会删除整个 SPIRE 部署和所有参与者命名空间，请在所有参与者完成实验后执行。
====

在已克隆 lab repo 的目录下运行：

[source,bash]
----
make -C automation teardown
----

这会删除父 Argo CD Application，级联删除所有子 Application 及其管理的资源（user1-10-spire-lab、zero-trust-workload-identity-manager 等命名空间）。

在删除前确认将被删除的资源：

[source,bash]
----
oc get ns -l app.kubernetes.io/part-of=spiffe-spire-lab --no-headers
----
